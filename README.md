# bravebycopilot

A lightweight Android browser prototype inspired by Brave, built with a Chromium-based WebView engine and a native C++ ad/tracker blocker.

## Features

- Brave-inspired UI shell
- Fast Android WebView browser engine
- Native C++ request filtering
- Block list for common ad/tracker domains
- Toolbar with back, forward, refresh, and shield toggle
- Private browsing style default setup

## Project structure

- `app/src/main/java/...` - Android app code
- `app/src/main/cpp/...` - native C++ blocker
- `app/src/main/res/...` - UI and layout resources

## Build

Open in Android Studio and sync Gradle.

## Notes

This version is intentionally lightweight and is meant as a practical starting point for a custom privacy browser built on Chromium-based Android technology.
